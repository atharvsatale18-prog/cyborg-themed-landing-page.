# NEXUS — Cyborg-Themed Landing Page

A responsive, futuristic landing page concept built with HTML, CSS, and vanilla JavaScript.

## Run locally
1. Extract the project folder.
2. Open `index.html` in a browser. No build tools or installation are required.
3. For a local development server, run `python -m http.server 8000` inside this folder and visit `http://localhost:8000`.

## Features
- Responsive desktop, tablet, and mobile layouts
- Futuristic cyborg / neural-interface visual design
- Sticky navigation and mobile menu
- Animated hero interface, data labels, and capability illustrations
- Scroll reveal effects and subtle cursor glow
- Accessible navigation labels and reduced-motion support

## Files
- `index.html` — page structure and content
- `styles.css` — responsive styling and animations
- `script.js` — menu and scroll interactions

## Customization
Edit the text in `index.html` and the CSS variables at the top of `styles.css`.
The contact button currently uses a placeholder `hello@nexus.example` address; replace it with your own contact address before publishing.

## Submission checklist
1. Create a GitHub repository and upload these three files plus this README.
2. Enable GitHub Pages (Settings → Pages → Deploy from a branch → `main` → `/ (root)`).
3. Record a short screen capture showing the page on desktop and mobile width.
4. Upload the recording to Google Drive and set General access to **Anyone with the link — Viewer**.
5. Submit the GitHub repository URL and the Google Drive recording URL in the task form.
